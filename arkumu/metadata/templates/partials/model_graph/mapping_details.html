Mapping Model Core

The central entity for storing CSV data transformation configurations.

Key Characteristics:
  • Inherits from UUIDModel (provides id, created_at, updated_at)
  • Stores flexible JSON configurations for GUI interpretation
  • Tracks validation status and execution history
  • Optimized with database indexes for performance
Model Methods:
  • get_dataset_count() - Count of source datasets
  • get_column_count() - Count of workspace columns
  • get_relationship_count() - Count of FK relationships
  • is_ready_for_execution() - Validation check
