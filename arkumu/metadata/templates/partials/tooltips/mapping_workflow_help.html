Mapping Workflow

1
Set Anchor Columns
For each dataset, mark the column that creates entities (usually 'id')
users.id, products.product_id, orders.order_number
2
Mark FK Columns
Identify columns that reference other datasets
orders.user_id → users.id
3
Handle Multi-Values
Split comma-separated values if needed
"skill1, skill2, skill3" → separate entities
4
Execute in Order
System processes anchor columns first, then FKs
💡 Pro Tip: Start with datasets that don't reference others (pure entities)
