⚙️ Create Automatic Type Assignment Rules

How This Works

1. You searched above and found resources matching your pattern

2. Create a rule below to automatically assign a semantic type to ALL those matching resources

3. When you process triples later, each matching resource will automatically get: resource|rdf:type|YourChosenType

Example: If you found resources like:

  • person_john_doe, person_mary_smith, etc.

Create a rule: Pattern "person_" → Type "arkumu:person"

Result: All will automatically get person_john_doe|rdf:type|arkumu:person
