What is Harmonization?

Harmonization creates semantic alignments between archive-specific properties and catalog-level properties while preserving original data integrity. This process uses configured rules to map your organization's metadata to standardized vocabulary terms.

Before starting:

  • Ensure harmonization rules are configured for your organization
  • Review any existing conflicts that may need resolution
  • Consider backing up your data if this is a first-time run
