1. Overview

The Arkumu component system is a collection of reusable UI components built with Django templates and Tailwind CSS. Each component supports multiple themes (Light, Dark, Blue) and can be easily customized through variable passing.

Key Features:

  • Multi-theme support with seamless switching
  • Modular component architecture
  • Consistent design language
  • Easy variable passing for customization
  • Responsive design built-in

3. Theme System

How Theme Switching Works

The theme system uses CSS classes applied to the body element. Components automatically adapt their appearance based on the active theme class.

Theme Classes:

  • theme-light - Default light theme
  • theme-dark - Dark theme with inverted colors
  • theme-blue - Blue accent theme

Theme Buttons Implementation:

<!-- Theme Switcher Buttons -->
<div class="flex space-x-4 p-4 rounded-lg">
  <button type="button" 
    class="theme-button px-4 py-1.5 rounded-full font-mono transition-colors
      bg-arkumu-light text-arkumu-blue border border-arkumu-blue hover:bg-blue-50
      theme-dark:bg-transparent theme-dark:text-arkumu-blue 
      theme-blue:bg-arkumu-light theme-blue:text-arkumu-blue"
    data-theme="blue">
    Blue
  </button>
  
  <button type="button" 
    class="theme-button px-4 py-1.5 rounded-full font-mono transition-colors
      bg-arkumu-light text-arkumu-dark border border-arkumu-dark hover:bg-gray-100
      theme-dark:bg-transparent theme-dark:text-arkumu-light 
      theme-blue:bg-arkumu-light theme-blue:text-arkumu-blue"
    data-theme="light">
    Light
  </button>
  
  <button type="button" 
    class="theme-button px-4 py-1.5 rounded-full font-mono transition-colors
      bg-arkumu-dark text-arkumu-light border-none hover:bg-arkumu-dark-hover
      theme-dark:bg-white theme-dark:text-arkumu-dark theme-dark:border 
      theme-blue:bg-arkumu-dark theme-blue:text-arkumu-light"
    data-theme="dark">
    Dark
  </button>
</div>

JavaScript Theme Controller:

// Theme switcher functionality
document.addEventListener('DOMContentLoaded', function() {
  const themeButtons = document.querySelectorAll('[data-theme]');
  
  themeButtons.forEach(button => {
    button.addEventListener('click', function() {
      const theme = this.getAttribute('data-theme');
      
      // Apply theme class to body
      document.body.classList.remove('theme-dark', 'theme-light', 'theme-blue');
      document.body.classList.add(`theme-${theme}`);
      
      // Update button states
      themeButtons.forEach(btn => {
        btn.classList.remove('ring-2', 'ring-white');
      });
      this.classList.add('ring-2', 'ring-white');
      
      // Store preference
      localStorage.setItem('arkumu-theme', theme);
    });
  });
  
  // Apply saved theme on page load
  const savedTheme = localStorage.getItem('arkumu-theme') || 'light';
  document.body.classList.add(`theme-${savedTheme}`);
});

4. Component Implementation

Including Components in Templates

Components are included using Django's {% templatetag openblock %} include {% templatetag closeblock %} template tag. The path corresponds to the component's location in the file structure.

Basic Syntax:

{% templatetag openblock %} include 'components/category/component_name.html' {% templatetag closeblock %}

With Variables:

{% templatetag openblock %} include 'components/category/component_name.html' with variable1="value1" variable2="value2" {% templatetag closeblock %}

Theme-Aware Component Structure

Each component uses Tailwind CSS classes with theme prefixes to support automatic theme switching: 

<!-- Example: Theme-aware button -->
<button class="px-4 py-2 transition-colors
               border border-arkumu-dark text-arkumu-dark
               theme-dark:border-arkumu-light theme-dark:text-arkumu-light
               theme-blue:border-arkumu-blue theme-blue:text-arkumu-blue">
  {% templatetag openvariable %} button_text|default:"Default Text" {% templatetag closevariable %}
</button>

Theme Class Patterns:

  • border-arkumu-dark → theme-dark:border-arkumu-light
  • text-arkumu-dark → theme-dark:text-arkumu-light
  • bg-arkumu-light → theme-dark:bg-arkumu-dark
  • Blue theme uses theme-blue:*-arkumu-blue for accent colors

5. Passing Variables to Components

Variable Syntax

Variables are passed using the with keyword in the include statement: 

{% templatetag openblock %} include 'components/buttons/primary_button.html' with button_text="Click Me" {% templatetag closeblock %}

Default Values

Components use Django's default filter to provide fallback values: 

<!-- Inside component template -->
<button>{% templatetag openvariable %} button_text|default:"Default Button Text" {% templatetag closevariable %}</button>

Multiple Variables

Pass multiple variables by separating them with spaces: 

{% templatetag openblock %} include 'components/cards/card.html' with title="Project Title" subtitle="Project Subtitle" year="2024" institution="University Name" button_text="View Project" {% templatetag closeblock %}

Complex Variables

For multiple contributors or categories, use numbered variables: 

{% templatetag openblock %} include 'components/cards/card.html' with contributor1_name="John Doe" contributor1_role="Designer" contributor2_name="Jane Smith" contributor2_role="Developer" category1="Web Design" category2="Frontend Development" {% templatetag closeblock %}

7. Custom CSS Usage

When Custom CSS is Needed

The Arkumu component system is built primarily with Tailwind CSS classes to maintain consistency and leverage the utility-first approach. However, there is one specific case where custom CSS was necessary: the Tag component.

Tag Component Special Case

⚠️ Why Custom CSS was Required:

The Tag component needed a text highlight effect where the background wraps each individual line of text, rather than creating a single rectangular background. This specific visual effect cannot be achieved with standard Tailwind utilities.

Custom CSS Implementation:

<!-- Text Highlight Component with Background that Wraps Each Line -->
<style>
  .highlight-text {
    display: inline;
    box-decoration-break: clone;
    -webkit-box-decoration-break: clone;
    padding: 0.25rem 0.5rem;
    line-height: 2.2; /* Espacio entre líneas para que no se superpongan */
    
    /* Colores por tema */
    background-color: #1E1E1E;
    color: #FAF9F6;
  }
  
  .theme-dark .highlight-text {
    background-color: #FAF9F6;
    color: #1E1E1E;
  }
  
  .theme-blue .highlight-text {
    background-color: #2B7EF2;
    color: #FAF9F6;
  }
</style>

<p>
  <span class="highlight-text font-mono text-sm md:text-base lg:text-lg xl:text-xl leading-[2.2] md:leading-[2.2] lg:leading-[2.2] xl:leading-[2.5]">
    {% templatetag openvariable %} label_text|default:"Este es un texto de ejemplo que se ajustará por líneas, con el fondo adaptándose al contenido exacto en cada línea." {% templatetag closevariable %}
  </span>
</p>

Key CSS Properties Explained:

  • box-decoration-break: clone - Makes the background wrap each line individually
  • display: inline - Allows the text to flow naturally and break across lines
  • line-height: 2.2 - Provides adequate spacing to prevent background overlap
  • Theme-specific colors - Custom CSS handles theme switching for the highlight effect

Why Tailwind Wasn't Sufficient:

Tailwind CSS doesn't provide utilities for box-decoration-break, which is essential for creating this line-wrapping highlight effect. This property is crucial for making the background adapt to the actual text content on each line, rather than creating a single rectangular block.

✅ Design Principle:

All other components in the Arkumu system use pure Tailwind CSS classes. Custom CSS should only be used when Tailwind's utilities cannot achieve the desired visual effect, as demonstrated in this Tag component example.
